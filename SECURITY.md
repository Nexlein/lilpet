# Sécurité

lilpet est un projet personnel. Pour signaler une faille, dans le firmware, l'app PC publiée sur GitHub Pages ou les
scripts, passer par le signalement privé de GitHub (onglet **Security**, « Report a vulnerability » :
<https://github.com/Nexlein/lilpet/security/advisories/new>), et non par une issue publique.

Seule la dernière [Release](https://github.com/Nexlein/lilpet/releases) est suivie.
